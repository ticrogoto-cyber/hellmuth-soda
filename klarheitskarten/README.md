# Klarheitskarten

Projektordner für die Produktreihe **Klarheitskarten** (Print-on-Demand-Kartenspiele über QPMN + Shopify).

Erstes Produkt: **Klarheitskarten I – Selbstbetrug**.

## Struktur

```
klarheitskarten/
  00_briefing/          Strategie-/Briefingdokument (Single Source of Truth)
  01_text/              Master-CSV der 52 Karten, Regelkarten, Produkttext
  02_design/            Vorlagen, Schriften, Layoutdateien
  03_exports/           Druckdaten-Exporte (Karten, Regeln, Rückseite, Box, Proofs)
  04_qpmn/              QPMN-Specs, Anfragetext, Sample-Notizen, Uploads
  05_shopify/           Shop-Texte (Beschreibung, FAQ, SEO), Launch-Assets
  06_feedback/          Testkäufer-Feedback und Issue-Log
  07_launch/            Launchtext (Substack), Social Posts, Newsletter-Footer
```
